# rice/val

Based on https://github.com/revaljonathan/val-niri, adapted for sai-desktop.

- WM: niri  |  bar: waybar  |  notifications: dunst  |  launcher: rofi
- terminal: kitty (fish)  |  files: thunar, yazi  |  browser: brave
- colours: matugen, generated from the wallpaper  |  wallpaper: awww
- font: JetBrains Mono  |  icons: Papirus

Changes from upstream: their private quickshell is replaced by waybar, rofi and dunst;
laptop-only bits (battery, backlight, suspend, render device) removed; outputs set for
HP V22 (HDMI-A-1, left) + AOC Q27G11E (DP-2, 180 Hz).

Keys: Super+D or Super+Space apps, Super+V clipboard, Super+E thunar, Super+N yazi,
Super+B brave, Super+Z pick wallpaper, Super+Shift+Z random wallpaper, Super+W overview,
Super+Shift+arrows move windows, Super+Ctrl+arrows switch monitor, Super+Shift+E log out.
